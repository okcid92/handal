ÉTAPE 2 — RÉÉCRIRE plagiat-detector.ts
═══════════════════════════════════════════════════════════════

Fichier : src/server/analysis/plagiat-detector.ts

A) METTRE À JOUR LES TYPES

   Remplacer l'interface de résultat actuelle par :

   export interface DetailedScores {
     cosine    : number;   // 0-1
     jaccard   : number;   // 0-1
     ngram     : number;   // 0-1
     winnowing : number;   // 0-1 NOUVEAU
     lcs       : number;   // 0-1 NOUVEAU
     style     : number;   // 0-1 NOUVEAU
     simhash   : number;   // 0-1 NOUVEAU (indicateur seul)
     semantic ?: number;   // 0-1 OPTIONNEL (Python)
     combined  : number;   // 0-1 score final
     riskLevel : 'low' | 'medium' | 'high';
   }

B) AMÉLIORER LES 3 ALGOS EXISTANTS

   cosine() :
   - Utiliser tokenizeAndStem() au lieu de tokenize()
   - Implémenter TF-IDF correct (TF × IDF) au lieu de simple fréquence
   - Garder la similarité cosinus

   jaccard() :
   - Utiliser tokenizeAndStem() au lieu de tokenize()
   - Pas d'autre changement

   ngram() :
   - Combiner bigrams (poids 60%) + trigrams (poids 40%)
   - Utiliser le coefficient de Dice : 2×|A∩B| / (|A|+|B|)
   - Avant : seulement bigrams avec jaccard simple

C) AJOUTER 4 NOUVEAUX ALGORITHMES

   ─── Winnowing / Shingling ───
   Détecte : reordonnancement de paragraphes, copie partielle
   Paramètre k=5 (taille des shingles), fenêtre=4
   Étapes :
   1. Tokeniser le texte
   2. Générer tous les k-shingles (séquences de k tokens)
   3. Hasher chaque shingle (hash polynomial simple)
   4. Sliding window : garder uniquement le hash minimum de chaque fenêtre
   5. Comparer les ensembles de fingerprints : Dice coefficient
   Retourner 0 si moins de k tokens dans l'un des textes

   ─── LCS (Longest Common Subsequence) ───
   Détecte : plagiat chirurgical (mots supprimés/ajoutés)
   Optimisation obligatoire : matrice 2 lignes (O(n) mémoire)
   Limite : max 500 tokens par texte pour éviter O(n²) bloquant
   Score : 2 × LCS_length / (len_A + len_B)
   Utiliser tokenizeAndStem()

   ─── Analyse Stylistique ───
   Détecte : paraphrases conservant la structure rhétorique
   Métriques à comparer :
   - Longueur moyenne des phrases (mots/phrase)
   - Longueur moyenne des mots (chars/mot)
   - Densité de ponctuation (signes/mots)
   - Diversité lexicale (mots uniques/total)
   - Nombre de paragraphes
   - Densité de connecteurs logiques FR :
     ['cependant','néanmoins','toutefois','donc','ainsi',
      'par conséquent','en effet','de plus','en outre',
      'premièrement','deuxièmement','enfin','finalement',
      'or','c est pourquoi','par ailleurs','d ailleurs']
   Score par métrique : 1 - |a-b| / max(a,b)
   Score final : moyenne des 6 métriques

   ─── SimHash ───
   Détecte : documents quasi-identiques (indicateur rapide)
   Utiliser 64 bits
   Score : bits identiques / 64
   ATTENTION : ne pas inclure dans le score combiné,
               seulement retourner comme indicateur

D) NOUVELLE FORMULE DU SCORE COMBINÉ

   Sans semantic (Python non disponible) :
   combined = 0.30×cosine + 0.20×jaccard + 0.20×ngram
            + 0.15×winnowing + 0.10×lcs + 0.05×style
   (simhash exclu du calcul)

   Avec semantic (Python disponible) :
   combined = 0.20×cosine + 0.10×jaccard + 0.15×ngram
            + 0.15×winnowing + 0.15×semantic
            + 0.15×lcs + 0.05×style

   Niveaux de risque (CONSERVER les seuils Handal) :
   - low    : combined < 0.20   (< 20%)
   - medium : 0.20 ≤ combined < 0.70
   - high   : combined ≥ 0.70

E) FONCTION PRINCIPALE

   export async function analyzePlagiarism(
     textA: string,
     textB: string,
     semanticScore?: number
   ): Promise<DetailedScores>
   
   Cette fonction appelle tous les algos et retourne DetailedScores complet.
